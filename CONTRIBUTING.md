# Contributing to FlowState

Thank you for helping. FlowState is beta software maintained by Dr. Rüdiger Groß (Institute of Molecular Virology,
Ulm University Medical Center).

- **Problems and ideas:** open an issue (templates for bug reports and ideas), or write to flow@nanoscale.app.
  Never attach unpublished data or data that identify patients; a small public, anonymised or synthetic FCS file is
  the best way to show a problem.
- **Code:** for anything larger than a small fix, please get in touch first. Run `npm run typecheck` and `npm test`
  before a pull request, and add a test for the behaviour you change. Keep user-facing text short and plain.

  (AGPL-3.0-only). By opening a pull request you confirm that you wrote the code or may contribute it under this
